# ADR-0003: Long-term positioning — Expert AI Backend Architect

## Status
ACCEPTED

## Date
2026-03-05 (normalized; original decision predates this edit)

## Context
Artificial intelligence is transforming software engineering. Most developers focus only on prompts or tools, while enterprises need engineers able to integrate AI into real systems.

As a senior Java backend engineer, the goal is to reach a high-value expert position rather than remaining a standard backend developer.

## Decision
Long-term positioning:

Expert backend engineer specialized in AI integration for enterprise systems.

This includes mastering:
- LLM integration in backend services
- Retrieval Augmented Generation (RAG)
- AI system architecture
- cost and performance considerations
- security and compliance constraints
- observability and logging of AI systems

The objective is not to become a machine learning researcher, but to become a key technical leader able to design AI-enabled systems.

## Consequences
- Increases long-term market value
- Enables transition to tech lead or architect roles
- Ensures relevance despite AI evolution
- Differentiates from standard backend developers

All learning and projects should support this positioning.
