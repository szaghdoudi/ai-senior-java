# ADR-0003: Long-term positioning — Expert AI Backend Architect

## Status
ACCEPTED

## Context

Artificial intelligence is transforming software engineering.
However, most developers focus only on prompts or tools,
while enterprises need engineers able to integrate AI into real systems.

As a senior Java backend engineer,
the goal is to reach a high-value expert position
rather than remaining a standard backend developer.

## Decision

The long-term positioning will be:

**Expert backend engineer specialized in AI integration for enterprise systems.**

This includes mastering:
- LLM integration in backend services
- Retrieval Augmented Generation (RAG)
- AI system architecture
- cost and performance considerations
- security and compliance constraints
- observability and logging of AI systems

The objective is not to become a machine learning researcher,
but to become a key technical leader able to design AI-enabled systems.

## Consequences

This positioning will:
- increase long-term market value
- enable transition to tech lead or architect roles
- ensure relevance despite AI evolution
- differentiate from standard backend developers

All learning and projects should support this positioning.
