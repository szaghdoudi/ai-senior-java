# Project Checkpoint - 2026-03-14

## Summary
The first end-to-end RAG pipeline is now operational.

## What is working
- PostgreSQL/pgvector is integrated and reachable by the application.
- Flyway migrations run successfully at startup.
- `rag_chunks` is populated through the ingestion pipeline.
- Local markdown documentation is loaded, chunked, embedded, and indexed.
- `/api/ai/ask` returns citations when RAG is enabled.

## Current limitation
- Retrieval quality is still limited because embedding is generated by placeholder provider.
- The RAG pipeline is functionally connected, but semantic ranking is not yet reliable enough.

## Architectural status
- Runtime database access uses R2DBC.
- Schema migrations use Flyway with JDBC
- Retrieval and ingestion are separated behind explicit ports and adapters.
- The system is ready to accept real embedding provider without major refactoring.

## Next priority
Implement a real embedding provider and re-index documents to improve retrieval relevance.
